# Stan-w-ispnext Tap

## How do I install these formulae?

`brew install stan-w-ispnext/tap/<formula>`

Or `brew tap stan-w-ispnext/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "stan-w-ispnext/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
